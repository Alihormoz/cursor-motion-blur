# Cursor Motion Blur

I love Windows. ❤️

Windows is great, but it still has some small UI and animation details that could be better. One of them is the lack of smooth **cursor motion blur**, similar to the effect seen in macOS.

So I decided to build **cursor-motion-blur** to experiment with bringing smoother and more modern cursor animations to Windows.

## ✨ Features

- 🖱️ Smooth cursor animations
- 🌫️ Cursor motion blur
- ⚡ Lightweight and responsive
- 🎨 Inspired by modern UI effects in macOS

## ⚡ Fast Installation
Or download the latest release from **Releases** and run:

```
    cursor-motion-blur.exe
```

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Alihormoz/cursor-motion-blur.git
cd cursor-motion-blur
start cursor-motion-blur.exe
```
## ▶️ Usage

Launch the application and move your mouse. The motion blur effect will be applied automatically.

> ⚠️ This project have a performance lost.
